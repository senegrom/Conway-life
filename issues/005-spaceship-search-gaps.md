# Select and attack a current spaceship-search gap

## Status audit first

Check the Spaceship Search Status Page, Spaceship Discussion thread, recent LifeWiki news, and ikpx2/LSSS/LLSSS threads. Do not rely on a cached unknown-speed list.

## Candidate tools

- LSSS: very fast orthogonal slice searches; substantial disk usage.
- LLSSS: flexible Rust suite and bounded-disproof modes.
- ikpx2: SAT-based partial extension, especially for oblique ships.

## Candidate examples recorded on 2026-08-23

\((2,1)c/7\), \(c/8\), \(3c/8\), diagonal \(c/9\).

## Acceptance criteria

For a discovery: exact RLE, period/displacement proof, independent run and status-page comparison. For a negative result: completeness argument, exact command and commit, checkpoint/final digest and independent checker.
